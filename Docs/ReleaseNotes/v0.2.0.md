## ETL-SQL Unofficial v0.2.0

This unofficial release introduces the core query dialect, database connectors (MSSQL, Postgres, Oracle), flatfile XML/JSON support, parallel execution, notifications, and basic CLI linter.

### Highlights

**Core Query Dialect & Standard Library**
- Support for `DISTINCT`, `TOP`, `LIMIT`, `MERGE`, `OFFSET`, `NTILE`, `STRING_AGG`, and transactional statements (`COMMIT`, `ROLLBACK`, `THROW`).
- Support for `#temp` tables with query plan indexes (`CREATE INDEX`) and query plan tracing via `EXPLAIN`.

**Database & File Connectors**
- Added initial support for MSSQL, Postgres, and Oracle database engines.
- Read/write capabilities for XML and JSON files.

**Control Flow & Parallel Execution**
- Parallel execution pipelines (`PARALLEL`), cross-script execution (`RUN SCRIPT`), and directory synchronization tasks.

**Notifications & Transfer Connectors**
- Added `SEND EMAIL` notification capability.
- Added file transfer connectors (SFTP/SSH, FTP, Azure Blob).

**Linter & UI Foundations**
- Added a command-line script editor, local test harness (`--test`), and baseline security linter.

Full details in [CHANGELOG.md](https://github.com/etl-sql/ETL-SQL/blob/v0.7.0/CHANGELOG.md).
