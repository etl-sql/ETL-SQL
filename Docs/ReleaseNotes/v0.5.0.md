# ETL-SQL v0.5.0 *(Unofficial)*

**Released:** 2026-05-04

Introducing the **Report Portal Web App**, **automated report subscriptions**, and the **Apache Arrow spill format**.

---

## Release Summary

v0.5.0 is an unofficial pre-release that introduces the **Report Portal Web Subsystem**. This addition provides a multi-user dashboard portal featuring JWT authentication, role-based access control (RBAC), folder organization, and direct browser chart rendering (ECharts). It also adds automated **Report Subscriptions** to export reports via email, a high-performance **Apache Arrow spill format** for temp table caching, and official cross-platform installers (MSI, deb, and DMG).

## Highlights

### Report Portal Web App (Phases 1–6)

**Audience:** Report Consumers · Administrators · Evaluators

**Problem:** Distributing generated reports previously required saving static files on shared disks or executing command-line scripts individually, limiting concurrency and team collaboration.

**Solution:** A Kestrel-hosted multi-user web dashboard:
- **Security:** User authentication secured by JWT, OIDC-ready logins, and folder-level RBAC.
- **Reporting:** Direct in-browser rendering of Markdown and interactive ECharts charts.
- **Execution Tracking:** Historical snapshot and job execution logs.

---

### Automated Report Subscriptions

**Audience:** Report Consumers · Administrators

**Problem:** Report users had to log in to see current statistics, with no native automated delivery method.

**Solution:** Email subscriptions:
- Automatically exports report visuals and tables.
- Sends reports via SMTP as Markdown text or active hyperlinks.
- Command API: `EXPORT REPORT ... SEND EMAIL ...`.

---

### Apache Arrow Spill Format

**Audience:** Script Authors · Administrators

**Problem:** Swapping large `#temp` tables to disk using native C# object streams consumed significant CPU cycles and caused memory exhaustion.

**Solution:** The high-speed **Apache Arrow IPC spill format**:
- Serializes rows into flat, structured memory layouts.
- Streams columns directly to temporary directories without serialization overhead.
- Supports client-side credentials auto-decryption.

## Improvements

### Language & Engine
- Added `QUALIFY` clause filtering for window function values.
- Added standard `FILTER (WHERE ...)` constraints to aggregate functions.
- Loop statements support implicit ranges: `FOR @i TO 10`.
- Added cursor status checks: `@@FETCH_STATUS`.

### Report Portal & Visualization
- Added a `/health` endpoint for DB and orchestrator monitoring.
- Export audit logs to CSV for compliance audits.

### VS Code Extension & IDE
- Added dot-notation suggestion rankings and member-access completions to IntelliSense.
- Overhauled TUI with path completion, Smart Copy, Compare Mode, and a status bar.

### Connectors
- Added native connectors for **Snowflake** and **BigQuery** databases.

## Performance

- **Arrow IPC Spill** — Bypassed JSON/CSV string parsing during spilling, speeding up disk writes by up to 4×.

## Security

- **JWT Rotation:** Added `GENERATE JWT_SECRET` for secure portal token generation.
- **Secure Configurations:** Implemented path traversal validation, HSTS headers, and JWT key length checks.
- **Explicit Overrides:** Migrated legacy security properties to structured `SET ALLOW_...` statements.
