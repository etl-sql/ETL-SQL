## ETL-SQL v0.9.0

This release delivers **ECharts SSR PDF Export**, **GOTO Checkpoint & Resumable Scripts**, a native **MySQL** connector, and the **EXPLAIN ANALYZE** query profiler.

---

### Highlights

#### 1. Resumable Checkpoints & GOTO Statements
Adds control flow capabilities to safely pause and resume execution of long-running data pipelines.
* **`LabelName:` Section Checkpoints:** Top-level labels act as auto-serialization boundaries. In-flight `#temp` tables (spilled via Arrow IPC) and variable contexts are saved to disk as a named checkpoint.
* **`GOTO LabelName;` Control Flow:** Supports jumping out of loops, nested conditional blocks, and exception handlers. Jumps *into* nested blocks are blocked at compile time.
* **`--session` and `--resume` CLI flags:** Restores script variable scopes and temp tables, resuming execution from the last reached checkpoint to skip completed steps.
* **LSP Integrations:** Exposes section labels in the document outline, and autocompletes GOTO targets.

#### 2. Native MySQL & MariaDB Connector
* **High-Performance Driver:** Introduces a native `MySqlConnector` provider. This bypasses the slower ODBC driver path, handles native dialect translations, and catches provider anomalies at the connector boundary.
* **Catalog Exploration:** Adds support for discovery of database schemas, procedures, and catalog tables.

#### 3. ECharts SSR Chart Export
* **Server-Side SVG Rendering:** Integrated ECharts SSR engine. Chart visuals are rendered as real vector graphics inside exported PDF reports, replacing mock placeholders.
* **Formatted Markdown Tables:** Tightened Markdown and PDF table formats to display numbers, dates, and text columns using aligned layout cells.

#### 4. Query Profiling & Spill Telemetry
* **`EXPLAIN` and `EXPLAIN ANALYZE`:** Statements to output execution plans (costs, estimated rows, operators) or trace actual run times and disk spill footprints.
* **Performance Telemetry:** Telemetry blocks include spilled disk size metrics (`SpilledBytes`) to track disk thrashing.
* **Tuning Documentation:** Shipped a comprehensive performance tuning guide (`Performance.md`) detailing memory limits, spill configurations, and VM scale parameters.

---

### Fixed

- **VS Code Extension** — Stabilized REPL heartbeats, added Unix executable permissions during npm package builds, and resolved terminal command escaping.
- **Fail-Fast Resumes** — Calling `--resume` without a session identifier or with empty checkpoints throws a clear exception instead of silently running from the start.
