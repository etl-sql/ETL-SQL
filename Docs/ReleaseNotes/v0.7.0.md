## ETL-SQL v0.7.0

This release introduces **Advanced Drill-Down & Highlighting**, **ETL Notebooks (`.etlnb`)**, **Shared Datasets**, **Lineage 2.0**, and the **TUI 2.0 Console**.

---

### Highlights

#### 1. Interactive Dashboards & Drill-down
Enhances static reporting with interactive analytics and drill-through capabilities.
* **Hierarchical Drill-Down:** Adds `DRILL_IN` and `DRILL_DOWN` statements for in-place detail views, and `DRILL_TO` to navigate to other dashboards while passing parameter state.
* **Cross-Visual Highlighting:** Clicking segments in one chart highlights matches and displays ghost-dimmed outlines for unrelated items across all other page visuals.
* **New Visual Elements:** Adds `MAP` (supporting GeoJSON mapping files), `GAUGE`, `BOXPLOT`, `WATERFALL`, `BUBBLE`, `RADAR`, and `CANDLESTICK` visual types.
* **Input Visuals:** Renders interactive `TEXTBOX`, `NUMBERBOX`, and `CHECKBOX` parameters, and adds `RELDATEPICKER` calendars.
* **Deferred Execution:** Supports a `RUN` button that batches slicer parameter changes, preventing report refreshes on every single user click.
* **Paginated Layouts:** Adds `PAGINATED = ON` rendering templates with automatic table-header repetitions and page break formatting.

#### 2. ETL Notebooks (`.etlnb`)
* **VS Code Notebook support:** Native notebooks allowing cell-based script execution, REPL memory preservation, and IntelliSense connections autocomplete across cells.
* **Protocol Hardening:** Communication with the REPL process uses PascalCase JSON over stable OS pipes with periodic heartbeat checks.

#### 3. Shared Datasets & Lineage 2.0
* **Shared Cache Registry:** Reports can fetch datasets centrally from a cached registry, executing updates in the background and enforcing access policies.
* **Lineage 2.0 Metadata:** Implements a standard library of 20 lineage tags (e.g. `@pii` or `@sensitive`) with true-wins inheritance rules, exports datasets to OpenLineage JSON configurations, and generates Mermaid chart layouts.

#### 4. Lake Connectors & Dialect Upgrades
* **Snowflake & BigQuery:** Native connection configurations, query compile tasks, and authentication overrides.
* **QUALIFY Filtering:** Adds the `QUALIFY` clause to filter query results directly against window aggregate results.
* **Window `FILTER` Aggregate:** Supports standard `FILTER (WHERE ...)` clauses inside partition query functions.

---

### Fixed

- **Multi-Select Regression** — Resolved dropdown conflicts that over-wrote newer multi-select checkbox interfaces.
- **Path Handling** — Fixed file publish exceptions triggered when saving files across different disk volume letters on Windows.
