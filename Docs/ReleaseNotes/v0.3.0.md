## ETL-SQL Unofficial v0.3.0

This unofficial release introduces the initial VS Code Extension alpha, SSH security features, Serilog logging, hash join optimizations, and SQL pushdown improvements.

### Highlights

**VS Code Extension v0.1 Alpha**
- Integrated LSP parser supporting formatting, lineage hover, and smart CLI execution directly from the VS Code editor.

**Security, Encryption & Logging**
- Added SSH key pairing (`GENERATE SSH_KEY_PAIR`), connection altering (`ALTER CONNECTION`), and file encryption/decryption (`ENCRYPT FILE`, `DECRYPT FILE`).
- Integrated Serilog for application-wide logging and consolidated logs to the `logs/` directory.

**Performance & Query Optimizations**
- Implemented `CompoundKey` to optimize hash joins and handle mixed-type comparisons (string/numeric/date) across diverse sources.
- Enabled SQL pushdown execution and support for standalone `EXECUTE INTO #temp`.
- Added explicit column mapping support and column-level lineage tracking.

**Language Syntax**
- Supported `LIKE ESCAPE` and grouping sets (`ROLLUP` / `CUBE`).

### Changed

- **Syntax Standardization** — Migrated `ON FILE` to `ON FLATFILE` for file connections.

### Fixed

- **Thread Safety** — Eliminated deadlocks and silent exception swallowing under concurrent execution contexts.

Full details in [CHANGELOG.md](https://github.com/etl-sql/ETL-SQL/blob/v0.7.0/CHANGELOG.md).
