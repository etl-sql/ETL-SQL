## ETL-SQL v0.13.0

This release introduces native **Apache Arrow Snapshot Integration**, **Portal Execution Metrics & Observability**, and **Database-Level PII Encryption**.

---

### Highlights

#### 1. Apache Arrow Snapshot Integration
To improve reporting display latency and network performance, the snapshot system has transitioned to Apache Arrow IPC serialization formats.
* **Arrow IPC snap Packages:** The `SnapshotStore` compiles query outputs into compressed `.etlsnap` ZIP packages. These stream Arrow column batches directly to web UI clients.
* **Lazy-Loading UI rendering:** The Report Portal and front-end player decode Arrow IPC streams on-demand, skipping full JSON row materialization to handle large result grids efficiently.
* **Host-Bound At-Rest Encryption:** If `Portal:Dataset:AtRestKey` is left unconfigured, snapshots are encrypted at rest using a machine-bound key (Windows DPAPI LocalMachine or machine-id-derived AES-256-GCM) to ensure local data is locked to the host OS.

#### 2. Portal Execution Metrics & Observability
Provides operators with detailed resource tracking on historical query loads.
* **Resource Metrics Persistence:** Executions record CPU usage, peak memory working set, and run durations to the Portal database (via EF migrations supporting both SQLite and Postgres).
* **Live Lock Inspection:** The `SHOW LOCKS` statement queries active session and orchestrator-level resource locks, enabling developers to diagnose contention and script blocks.
* **Scripted Operational Telemetry:** Adds `SHOW PORTAL USAGE METRICS` and `SHOW PORTAL OPERATIONAL METRICS` statements inside `EXECUTE portal` contexts, allowing developers to query queue depth, refresh failure rates, and active queue counts directly.

#### 3. Language Server optimizations
* **Cross-File Declaration Resolution:** LSP `HoverProvider` and `DefinitionProvider` analyze all files in the current workspace, allowing `GO TO DEFINITION` actions on tables or procedures defined in adjacent scripts.
* **Keystroke Performance Cache:** Caches token definitions and metadata scans to eliminate latency when typing in large folders.

---

### Performance

- **Lineage Indexing** — Lineage tracking scans are indexed via `LineageTracker` to replace slow linear sweeps with O(1) lookups during evaluation.
- **TUI Frame Metadata Caching** — Re-rendering only modified sections of the Terminal IDE cuts CPU overhead while editing.

---

### Security

- **PII Encryption at Rest** — Encrypts database columns storing user emails and display names within the Portal database, using a key generated from the cluster Data Protection keyring.
- **ReDoS Backtracking Hardening** — Regular expressions inside core parsing routines are constrained by compiler generated regex patterns with `1000ms` timeouts to protect against ReDoS attacks.
