## ETL-SQL v0.10.0

This release introduces **Specification-Driven Development (Beta)**, a complete overhaul of the **Terminal IDE (TUI) console**, a native **Neo4j** connector, and **Orchestrator API Security**.

---

### Highlights

#### 1. Specification-Driven Development (Beta)
Enables compiling metadata specifications directly into execution-ready ETL-SQL scripts.
* **`gen-script` CLI:** Compiles standard JSON data contract specifications into documented ETL-SQL templates. These include source schema validations (`EXPECT SCHEMA`), confidence levels, casting rules, and quarantine table generation.
* **`extract-spec` Data Dictionary Parser:** Leverages PDFsharp to extract data dictionary pages from large vendor PDF documents, utilizing heuristic keyword scoring to index layouts automatically.
* **Prompt Instructions & Templates:** Shipped formatting schemas (`spec_pipeline.schema.json`) and runbooks to build vendor pipelines.

#### 2. Terminal IDE (TUI) Modernization
Transforms the basic console shell into a complete, productive terminal development workspace.
* **Explorer Sidebar & Tabs:** Adds collapsible file explorer sidebars and multi-tab script editing.
* **Enhanced Editor Engine:** Supports multi-cursor editing, drag-select text selection, F1 help overlays, and text search find/navigation (`F3` / `Shift+F3`).
* **Live Gutter Diagnostics:** Displays inline syntax warnings and compiler errors next to affected lines.
* **Metadata & Variable Discovery:** Gathers tables, views, and execution variables inside collapsible bottom panels, with asynchronous lazy-loaded Schema Explorer support.
* **Result Grid Inspection:** Cell-value navigation and detail popup views, with result-set caching per tab.
* **Asynchronous Execution:** Scripts can execute in the background without freezing the editor, and a command palette (`Alt+P`) manages tasks.
* **Terminal Charting:** Renders braille-based line charts and fractional-block bar charts directly inside the terminal.

#### 3. Connectors & Language Upgrades
* **Neo4j Graph Database:** Native connector supporting node and edge creation, Cypher executions, key merging, and metadata catalog checks.
* **REST Outbound Writing:** Supports writing and sending payload streams via REST connectors.
* **Lineage & Tag Imports:** Statements like `CREATE TAG` and `CREATE LINEAGE FROM ...` enable developers to import metadata profiles programmatically.
* **Soundex Scoring:** The `DIFFERENCE(s1, s2)` string function compares name similarity.

---

### Fixed

- **Parser Enhancements** — Corrected parser behavior for `LEFT SEMI` and `LEFT ANTI` joins, and tolerated trailing semicolons inside block scopes.
- **Cookbook Audit** — All 23 Cookbook templates have been validated to compile cleanly against the parser.

---

### Security

- **Orchestrator API Key (`X-Orchestrator-Key`)** — Ad-hoc execution APIs require authentication headers when bound to non-loopback network interfaces.
- **Spec Egress & Injection Protection** — Sanitizes spec dataset names to block traversal attempts, and restricts REST connectors from automatically following cross-domain redirects or transferring sensitive credentials.
