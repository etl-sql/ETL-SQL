## ETL-SQL v0.8.0

This release introduces the **Connector Certification Matrix**, **Doctor Probers**, **Scale Certification Harness**, **Persistent Lineage Catalog**, and **Snippet Library Expansion**.

---

### Highlights

#### 1. Connector Certification Matrix & Test Containers
Establishes a rigorous, automated integration testing suite across all 21 data connectors.
* **4-Class Testing Matrix:** Classifies connector tests into `MetadataOnly`, `MockedIntegration`, `LocalRealIntegration`, and `DockerRealIntegration`.
* **Emulator Testing:** Implements Testcontainers for live environment validations:
  - **FTP:** Docker-backed Alpine FTP server testing upload, download, and listing.
  - **SMTP:** Mailpit container testing email delivery and multi-row batch flows.
  - **BigQuery / Snowflake:** Emulator containers verifying auth and host-allowlist rules.
  - **Azure Blob:** Azurite emulator testing SasToken expirations and uploads.
* **Provider Exception Wrapping:** Standardizes error handling by wrapping native driver exceptions into structured `ExecutionException` types for 11 connectors, ensuring script runs fail gracefully with clean messages.

#### 2. `etl-sql doctor` Diagnostics
* **Quick & Full Profiles:** Added `--profile full` execution running network probes to verify dependencies (Report Portal API, SMTP server, SFTP endpoints, Azure Blob containers) and diagnostic checks.
* **Automation-Friendly Output:** Surfaces checks via `--json` formatting, and supports `--strict` triggers to return non-zero exit codes on warnings.

#### 3. Scale Testing Harness
* **`Test-ScaleCertification.ps1`:** Runs memory limits, CUBE grouping spills, and sort spills under controlled volume scales.
* **Cleanup Integrity:** Verifies all temp files and spill storage directories are deleted cleanly after task success or abrupt script aborts.

#### 4. Persistent Lineage History
* **Database Catalog:** Stores data lineage history in `SQLiteJobHistoryStore` (`LineageHistory` table) for all execution contexts.
* **SQL Query Surface:** Adds `SHOW LINEAGE HISTORY FOR TABLE <name>` and `SHOW LINEAGE HISTORY FOR TAG <key> [= 'value']` statements.
* **Stewardship Portal UI:** Added a dashboard showing active lineage histories, source files, PII identifiers, and task dependencies.

---

### Performance

- **Streaming XML Processing** — Refactored the XML connector to utilize a streaming `XmlReader` instead of reading the entire file DOM into memory, capping RAM usage on large files.

### Fixed

- **Snowflake Recursion** — Corrected a stack overflow bug inside `SnowflakeDataSource.CreateCommand` which repeatedly referenced its own instance.
- **VS Code Masking** — Enabled secure terminal inputs when prompting for `ENC:` passwords within VS Code notebooks.
