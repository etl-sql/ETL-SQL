## ETL-SQL v0.11.0

This release introduces **Secure Parquet Datasets**, **Script-First Portal Reconstruction**, and new **Operator Backup & Restore CLI tools**.

---

### Highlights

#### 1. Secure Dataset Subsystem
Designed to allow multi-user environments to share and cache datasets safely.
* **Globally Unique Dataset Names:** Replaces folder-scoped relative paths with stable dataset identifiers mapped under access controls.
* **Dataset to Folder ACL Linkage:** Integrates access control lists directly with folder rights. For example, assigning `PUBLIC` permission to a dataset evaluates it against the folder’s active reader permission, closing potential access leaks.
* **At-Rest Parquet Encryption:** The local dataset cache is saved in encrypted Parquet format. Access fails closed if a weak encryption key is detected, and the engine supports automatic key rotations.
* **`EXPORT` and `PUBLISH DATASET`:** Statements to package transport-encrypted datasets and import them on other servers securely.
* **Serve-Stale-With-Warning:** Options to serve cached data when refresh jobs fail, alerting viewers while preventing script crashes.

#### 2. Script-First Portal Reconstruction
Allows configuration of Report Portal environments using code, facilitating version control and environment replication.
* **`EXPORT PORTAL CONFIGURATION`:** Compiles all users, groups, memberships, folder trees, access control mappings, report registrations, and SMTP mail aliases into an idempotent `.etlsql` bootstrap script.
* **Database ID Independence:** Script definitions use logical names rather than SQL database IDs, making imports safe to run over existing databases.
* **Secrets Separation:** Configuration exports omit private key material and passwords, replacing them with `${...}` placeholders and emitting a requirements header.
* **`WHAT_IF` Validation:** Imports support validation modes (`SET WHAT_IF ON`) that assert secret and connection presence before execution.

#### 3. Operator CLI Tooling
* **`etl-sql init`:** Scaffolds starter configurations, generates a secure cryptographically strong JWT secret, and creates a runnable template script.
* **`etl-sql admin support-bundle`:** Compiles host health statistics, connection tests, and logs into a credential-redacted ZIP archive for support diagnostics.
* **Admin Backup & Restore:** `etl-sql admin backup` and `etl-sql admin restore` separate user configurations from secret keys. Restoration checks verify key versions, backup file integrity, and platform compatibility.

---

### Changed

- **Apache License 2.0 Transition** — Aligned licensing across the core engine, VS Code extension, and web artifacts.
- **Auto-Migrations** — The system executes automatic database migrations on startup, and fails fast if the schema cannot migrate successfully.

---

### Security

- **Safe Backup Permissions** — Backup files are written with owner-only access privileges (`0600`/`0700` equivalents on Windows/Linux) to prevent local user access.
