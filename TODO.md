### TUI — Incomplete / Partial Features

- [x] **Make IDE execution non-blocking and cancellable** — F5 now runs on a background task (`StartRun`/`ExecuteSource(ct)`), so the input loop stays responsive. A `⟳ RUNNING — Esc to stop` status pill shows while running; **Esc** cancels via the run's `CancellationTokenSource` (passed to `Evaluate(script, ct)`, with `OperationCanceledException` surfaced as "Execution stopped"). Concurrent runs are rejected. The Windows input read (`WaitForSingleObject` heartbeat) and the generic path wake every ~80 ms while running so the loop repaints live tree/message updates; the render is wrapped to tolerate a raced concurrent write. Tests cover the run lifecycle and the concurrent-run guard.
- [x] **Add live diagnostics while editing** — Extracted the lex/parse/lint pass into `AnalyzeAsync` (no evaluator, no execution), shared by F5 (logs to Messages) and a new debounced live pass. `MarkDirty` schedules `ScheduleLiveAnalysis`: 350 ms after the last edit it re-analyses on a background task (each edit cancels the previous), swaps the diagnostics list atomically, and wakes the input loop (`LiveAnalysisPending` heartbeat) so gutter markers refresh without F5. F8/Shift+F8 navigation is preserved, and diagnostics always reflect the current document. Tests cover the analysis pass (diagnostics, no execution, gutter map, cancellation) and the headless no-op.
- [x] **Multi-cursor typing** — Character insertion and Backspace already broadcast to secondary carets (verified by test). Closed the remaining gaps: `Delete` now broadcasts too; the auto-close/overtype shortcut is skipped in multi-cursor mode so the primary can't desync from the secondaries; and line-count-changing ops (NewLine, Paste, DeleteLine, DuplicateLine, and Delete/Backspace line-joins) collapse to a single caret so stale secondary indices can't corrupt the buffer. 9 tests added.
- [x] **Wire Shift+Tab backward navigation in snippet mode** — Already wired: `InputHandler.cs:262` routes Shift+Tab → `MoveToPrevPlaceholder`, and `FindPrevPlaceholder` walks backward across earlier lines (covered by `AutocompleteControllerTests`). No change needed.
- [x] **Add visual indicator for snippet mode** — A green `SNIPPET` pill now shows in the status bar while `SnippetModeActive`, plus a one-time hint `"Snippet mode — Tab: next · Shift+Tab: prev · Esc: exit"` on activation and a `"Snippet mode exited."` message on exit. Tests cover activation+hint and the no-placeholder case.
- [x] **Diagnostic gutter annotations** — The line-number gutter now draws a colored marker on diagnostic lines (`✗` red error, `⚠` yellow warning, `•` blue info), worst-severity-wins per line, sourced from `editor.Diagnostics` and rebuilt each frame. Pure derivation in `DiagnosticGutter` with tests.
- [x] **Compare mode horizontal scroll** — Each compare pane now has its own horizontal scroll (`CompareScrollCols`). ←/→ scroll the focused pane's columns (clamped to keep one visible), the header shows `cols a-b/total`, and Home resets both axes. Clamp logic (`ResultsPanel.MaxColumnOffset`/`ClampColumnOffset`) is shared by the renderer and input handler, with tests.
- [x] **Variables panel (feature parity with VS Code)** — Added a **Variables** bottom-pane tab (F4 cycle, clickable strip, F6 focus, per-tab persisted) rendering `evaluator.VarContext.GetVariablesWithMetadata()` as Name/Type/Value, scrollable, with secret/sensitive values masked and NULL shown distinctly. Tests cover the strip entry, view switching, and the data contract.
- [x] **Add a metadata/schema explorer, not only a file explorer** — The sidebar has a **Schema** mode alongside Files: connections → tables → columns, with **views in their own group** and `#temp` tables. Children load **lazily on expand** (connections build instantly; tables/views/columns fetch on first open) so large schemas don't pay an upfront cost. A clickable **⇄ Switch** row (mouse-friendly) and **Tab** toggle modes; a **⟳ Refresh schema** row reloads; Enter on a column (or `i` on any node) inserts the name at the cursor. Tests cover toggle, lazy load, views grouping, and insert (via a fake `IDatabaseSource`).
- [x] **In-editor Find** — `Ctrl+F` in editor focus runs a real text search (it already did; the results-row filter only applies when Results is focused). Added: the term persists (`FindTerm`), all matches are highlighted in the editor, the Find prompt pre-fills the last term, and **F3 / Shift+F3** navigate next/prev with wrap (F3 still cycles theme when no find is active). **Esc** clears the highlight. `TryFindNext`/`TryFindPrev` tested for wrap + case-insensitivity.
- [x] **Add explicit rollback-all-transactions command** — Added "Rollback all transactions" to the command palette. It reports the active `TranCount`, no-ops with a status when zero, prompts for confirmation, then calls `Evaluator.RollbackAllTransactions()` and logs success/failure to Messages (error message is generic — no provider detail).
- [x] **Persist and recover the editor workspace across restarts** — `WorkspaceStore` persists the session (open file paths, active tab, cursor/scroll, and a recovery snapshot of dirty buffers) under `%APPDATA%/etl-sql/workspace`, keyed by working directory. On launch the session is **silently restored** (clean tabs reopen from disk; the launched file stays open + active); a sentinel file detects an unclean shutdown and, when dirty snapshots exist, **prompts to recover**. Saves are debounced (and on clean exit); recovery files are owner-locked and buffers containing secrets are never snapshotted (no credentials/decrypted text/results/engine state persisted). Store + sentinel covered by tests.
- [~] **Detect files changed on disk and prevent silent overwrite** — A `FileChangeTracker` snapshots each file's mtime at load/save; `SaveScript` now detects external modification and prompts **Overwrite / Reload / Cancel** before clobbering. `IFileSystem` gained `GetLastWriteTimeUtc`; detection is tested via a fake FS. (Deferred: a live file-watcher with auto-reload for clean buffers, and a side-by-side Compare option.)
- [x] **Add result-cell navigation and inspection** — Results focus now tracks an **active cell** (`ActiveResultRow`/`ActiveResultCol`): arrow keys move it, the renderer scrolls to keep it visible (`FollowScroll`) and highlights it, and the header shows `R# C#`. **Enter** opens a scrollable inspector (`InspectActiveCell` → info overlay) for clipped/multiline/JSON/XML values. **Ctrl+C** now copies the active **cell**; whole-**row** and whole-**set** TSV are separate palette commands. Database **NULL** renders distinctly (grey italic) from an empty string, and the active cell takes priority. `FilterRows`/`FollowScroll` are shared, pure, and tested.
- [~] **Add reduced-capability terminal mode** — `TerminalCapabilities` detects `NO_COLOR` (colour off), `ETLSQL_TUI_ASCII` (ASCII glyphs), and `TERM=dumb` (both off); `NO_COLOR` is also honoured by Spectre's own renderer. Unicode markers degrade to ASCII when needed — the diagnostic gutter (`✗/•`→`x/*`) and the whole schema/file sidebar tree (arrows, icons, toggle/refresh rows). A minimum-size fallback (`<40x10`) shows a clear "resize" prompt instead of corrupted/overlapping panels. The editor is already keyboard-only (mouse is additive). Tests cover detection and the ASCII fallbacks. (Deferred: switching Spectre panel borders to `BoxBorder.Ascii` in ASCII mode.)
- [x] **Undo does not restore cursor position** — `UndoManager` now snapshots `(Lines, CursorLine, CursorColumn)` as an `EditorSnapshot`; `ConsoleEditor.ApplySnapshot` reloads the text and restores the caret (clamped to the restored buffer) on Undo/Redo. Tests added.
- [x] **REPL export supports only CSV** — `ReplUi.HandleExport()` now handles `markdown`/`md` (GFM table, pipe-escaped) and `json` (array of row objects) alongside `csv`. Formatting is in pure `FormatMarkdown`/`FormatJson` helpers with tests.
