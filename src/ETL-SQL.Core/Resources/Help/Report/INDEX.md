Report-SQL allows building interactive dashboards with visuals, pages, and navigation.\nKey Components:\n  - DATASET:    Cached data sources (CREATE DATASET #name AS SELECT ...)\n  - VISUAL:     Charts and widgets (CREATE VISUAL name AS TYPE ...)\n  - PAGE:       Layouts (CREATE PAGE name AS LAYOUT ...)\n  - CONTAINER:  Nested groups (CREATE CONTAINER name AS BOX ...)\n  - NAVIGATION: Menus (CREATE NAVIGATION name AS TAB ...)\n  - STYLE:      Reusable formatting (CREATE STYLE name ...)\nUse HELP REPORT <COMPONENT> (e.g. HELP REPORT VISUAL) for details.
