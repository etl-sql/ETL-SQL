# Make it a dashboard

A `.rptsql` file is the same language plus `CREATE VISUAL` and `CREATE PAGE`. The sample builds a bar chart and two KPI cards from one summary table and lays them out with `STRUCTURE = 'A A / B C'`.

**Preview Report** renders it next to the code. Save it as a file and the preview refreshes on every save: change `AS BAR` to `AS LINE` and save to see it change.
