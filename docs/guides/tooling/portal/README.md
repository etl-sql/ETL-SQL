# Portal User Guides

> **Applies to:** Solo · Team · Enterprise · SaaS

The ETL-SQL Portal is a web application for browsing, running, and sharing Report-SQL dashboards. These focused guides cover the tasks you perform as a report consumer — from finding a report to embedding it in another application.

> [!TIP]
> For Portal **administration** tasks (publishing reports, managing permissions, configuring SMTP for subscriptions), see the [Portal Administration](../../../administration/portal/README.md) section.

---

## In This Section

| Guide | What it covers |
| :--- | :--- |
| [Browsing and Running Reports](browsing-and-running-reports.md) | Catalog navigation, search, opening reports, interactive parameters (slicers, date pickers, multi-select), and freshness badges |
| [Exporting and Subscriptions](exporting-and-subscriptions.md) | Generating PDF/CSV/Excel snapshots on-demand and configuring scheduled email subscription delivery |
| [Sharing and Embed Tokens](sharing-and-embed-tokens.md) | Creating time-limited share links, generating embed tokens for external `<iframe>` hosting, and CORS/security considerations |
| [Saved Views and Bookmarks](saved-views-and-bookmarks.md) | Saving named parameter presets, restoring views, sharing defaults with colleagues |
