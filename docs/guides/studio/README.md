# Studio Guides

[« Back to Guides](../README.md)

These guides describe ETL-SQL Studio in **v0.21.0**, for Portal catalog authoring and the local
desktop host. Studio keeps the SQL script as the document; the canvas and helpers edit that script.

| Guide | Use it to |
| :--- | :--- |
| [Your first Studio report](first-report.md) | Build a report, inspect generated SQL, keep hand edits, and save and reopen in either host. |
| [Run and schedule a Studio pipeline](run-and-schedule.md) | Repair a bounded practice pipeline, follow its run, request Stop, and pin a saved revision to a schedule. |
| [Drafts, publishing and recovery](drafts-and-recovery.md) | Know where text is kept, publish with the right permissions, and recover from conflicts or host failures. |

The report and pipeline exercises have automated production-host journey coverage. An observed
walkthrough with a person new to Studio remains pending; these guides do not claim learner
understanding has been certified. See the [journey evidence and scope](../../architecture/decisions/studio-beginner-acceptance-assessment.md).

For language details, use the [syntax index](../../syntax-index.md). For Portal deployment and
job administration, use [Administration](../../administration/platform/README.md).
