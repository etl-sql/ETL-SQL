# v0.21.0 Bugs and Logic Audit

Reviewed the eight checked items in `TODO.md` §13.1 on 2026-10-12. Seven were verified and removed.
The transaction-clone item was repaired but retains its unverified Snowflake row-level acceptance.
Changes elsewhere in the working tree were preserved.

| Item | Finding and disposition |
| :--- | :--- |
| ODBC/Snowflake transaction clones | Copying references fixed initial enrollment but left stale references after rollback and gave views disposal ownership. A real ODBC test reproduced a second rollback during clone disposal. Both connectors now share live state and distinguish owning sources from table views. ODBC rollback/reuse passes; Snowflake lifecycle passes with a recording transaction. Live Snowflake row rollback remains open. |
| Index column rename | Existing implementation updates every affected definition, preserves uniqueness, and rebuilds keys after rows are renamed. Both composite key orderings pass. Removed. |
| Session-cache timer exceptions | Existing catch logs failures without rethrowing. A fault-injection regression invokes the timer callback, verifies error logging, repairs its configuration, and runs another pass. Removed. |
| Job cancellation versus completion | Existing lock preserves terminal states. Tests cover cancellation before start, cancellation after success/failure, and concurrent completion/cancellation. Removed. |
| BigQuery insert replay | Insert IDs did not make automatic retry safe. A simulated accepted write followed by HTTP 503 was replayed and reported success. Both connector and SDK insert retries are now disabled. Transport/provider failures return sanitized reconciliation guidance. Tests cover lost responses, HTTP failures, successful inserts, and row errors through the actual SDK with a controlled HTTP transport. Removed. |
| NULL unique keys | Index building was fixed, but `IsDuplicate` still fell through to a scan that could treat repeated NULL values as duplicates. It now returns false for a NULL key. Regression covers builder and duplicate lookup. Removed. |
| Completion positions | Existing oversized-column clamp works. Added negative-line handling and tests for oversized lines/columns and negative positions. Removed. |
| Debounce token lifetime | Replacement no longer disposed the old source, but document close still did and left the lint queue pending. Close now cancels both queues without taking disposal ownership. Unexpected action failures are logged and observed. Deterministic tests cover replacement, close, failure, and subsequent work. Removed. |

The BigQuery transport test also exposed that the SDK rejects engine `decimal` values. They now
serialize as invariant numeric strings; the test inspects the decompressed request to verify the value
and insert ID. No remote credentials or live BigQuery account are needed for these transport tests.

Google documents insert-ID deduplication as best effort, not an exactly-once contract:
[BigQuery streaming insert documentation](https://docs.cloud.google.com/bigquery/docs/write-api-rest).
A failed insert can still have accepted rows. The fix prevents automatic replay; callers must reconcile
the destination before resubmitting an ambiguous operation.
