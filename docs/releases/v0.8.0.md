# ETL-SQL v0.8.0

**Released:** 2026-05-25

Introducing the **Connector Certification Matrix**, **Doctor Probers**, **Scale Certification Harness**, and a **Persistent Lineage Catalog**.

---

## Release Summary

v0.8.0 establishes rigorous validation and audit trails across the ETL-SQL platform. The new **Connector Certification Matrix** classifies all 21 connectors into formal integration tiers and runs automated docker-backed emulators (FTP, SMTP, BigQuery, Azure Blob, Snowflake) to certify real-world behaviors. System verification is extended with the **Scale Certification Harness** (`Test-ScaleCertification.ps1`) for memory-bound testing, and an upgraded **Doctor CLI** that probes SMTP, SFTP, and cloud service endpoints. Data governance is now persistent, storing metadata histories in a relational store queried via `SHOW LINEAGE HISTORY` and displayed inside a new Portal lineage catalog.

---

## ⚠️ Breaking Changes & Required Actions

- **`SHOW_SECRETS` preferred syntax:** `SET SHOW_PASSWORDS` is deprecated and renamed to `SET SHOW_SECRETS`. Update pipeline scripts to use the new setting name.
- **Strict Doctor exit codes:** The `doctor` CLI run with `--strict` now returns a non-zero exit code on system warnings (such as outdated drivers or optional service timeouts), which may affect automated CI scripts.

---

## ⏳ Deprecations

- **`SET SHOW_PASSWORDS`**: Use `SET SHOW_SECRETS` instead. Support for the legacy syntax will be removed in a future release.

## Highlights

### Connector Certification Matrix & Test Containers

**Audience:** Script Authors · Administrators · Evaluators

**Problem:** Standard mock tests fail to capture real-world driver discrepancies, credential handling errors, or network timeout behavior for external connectors, leading to unexpected failures in production.

**Solution:** A 4-class connector certification framework (`MetadataOnly`, `MockedIntegration`, `LocalRealIntegration`, `DockerRealIntegration`) combined with Testcontainers emulators:
- **FTP:** Docker-backed Alpine server testing list, upload, and download round-trips.
- **Azure Blob:** Azurite emulator verifying SAS token expirations and upload streams.
- **SMTP:** Mailpit container testing email delivery and multi-row batch flows.
- **BigQuery / Snowflake:** Emulator containers verifying authentication and allowlists.
- **Exception Wrapping:** Audited and wrapped driver exceptions into structured `ExecutionException` types for 11 connectors (Oracle, ODBC, Excel, Parquet, Avro, FTP, Azure Blob, API, SMTP, Portal, Orchestrator).

---

### Persistent Lineage Catalog & History Queries

**Audience:** Administrators · Report Consumers

**Problem:** Column and table lineage was previously transient, calculated in-memory during single executions, making it impossible to audit compliance histories or track dataset drift over time.

**Solution:** A persistent lineage storage engine (`SQLiteJobHistoryStore`) combined with query syntax and portal views:
- **Relational History:** Automatically records lineage metadata from all portal report runs, ad-hoc CLI executions, and dataset refresh tasks.
- **SQL History Queries:** Query lineages directly in scripts:
  - `SHOW LINEAGE HISTORY FOR TABLE <name>;`
  - `SHOW LINEAGE HISTORY FOR TAG <key> [= 'value'];`
- **Lineage Catalog UI:** A dedicated Portal interface to trace source files, filter columns, identify PII indicators, and export audit trails to CSV.

```sql
-- Query who and what has written to the customers table historically
SHOW LINEAGE HISTORY FOR TABLE customers LIMIT 10;
```

---

### `etl-sql doctor` Diagnostics & Probes

**Audience:** Administrators

**Problem:** Troubleshooting connection configurations, permission issues, or firewall blocks across remote database engines, mail servers, or cloud storage required manually writing test scripts.

**Solution:** Expanded diagnostic probes in the `doctor` command:
- `--profile full`: Runs automated network and protocol checks to verify SMTP, SFTP, Azure Blob, and Portal api connectivity.
- `--json`: Formats diagnostic reports for easy processing in automated scripts.
- `--strict`: Fails the execution (exit code 1) on any detected warning.

```powershell
# Perform a full service connection test and output JSON
etl-sql doctor --profile full --json --strict
```

---

### Scale Certification Harness

**Audience:** Administrators · Evaluators

**Problem:** Standard unit tests run with minor mock datasets and fail to prove engine stability, memory limits, or spill cleanup behaviors under heavy volume.

**Solution:** The new `Test-ScaleCertification.ps1` harness:
- Executes standardized scale tests across Smoke, Standard, and Stress tiers.
- Verifies that `TotalSpilledBytes > 0` on window, sort, and aggregation spill paths.
- Asserts that all temporary files and spill folders are deleted cleanly after task completion (or immediate termination).

## Improvements

### Language & Engine
- Refactored the XML connector to use a streaming `XmlReader`, capping memory allocations when reading large files.
- Added 13 new built-in snippets to TUI and LSP autocomplete databases.
- Documented ODBC and Excel exception rules directly in the architecture guides.

### Portal & Visualization
- Enabled read-only report users to inspect and download report snapshots while blocking refresh executions.
- Added audit event tracking (`EXPORT_CSV`, `EXPORT_PDF`) for compliance.

### VS Code Extension & IDE
- Added TUI editor autocomplete support for temp table names.
- Password prompt input fields securely mask password entry inside VS Code notebooks.

### Connectors
- Hostname normalization and JWT properties stabilized for Snowflake connectors.

---

## Performance

- **Streaming XML Processing** — Bypassed full DOM loading for XML connectors, reducing memory consumption by up to 90% for large feeds.
- **TUI suggestions caching** — autocomplete matches are cached to optimize text entry latency.

---

## Security

- **Credential Masking:** Confirmed password/API key redaction across support bundles, telemetry outputs, and the `doctor` terminal rendering.
- **SAS Expiry Guards:** Azure Blob connector enforces SAS Token expiration dates during transfer checks.
- **Unix Permissions:** Generated machine keys are written with strict owner-only permissions (`0600`).

---

## Bug Fixes

- Resolved a Snowflake stack overflow bug inside the command builder.
- Fixed a VS Code password prompt block inside notebook REPLs.
- Closed an SLT coverage gap by registering `MergeStatementHandler` in the test runner.
- Added negative-path tests for missing tables and invalid SQL in Oracle connectors.

## Upgrade Guide

Standard upgrade — replace binaries and restart services.

Note that `doctor` calls in build scripts using the `--strict` flag will now fail if optional connection checks fail. Review diagnostic settings before upgrading.
