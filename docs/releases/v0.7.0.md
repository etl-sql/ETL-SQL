# ETL-SQL v0.7.0

**Released:** 2026-05-18

The first official release, introducing **interactive reporting dashboards**, **VS Code ETL Notebooks (`.etlnb`)**, **Shared Datasets**, **Lineage 2.0**, and the **TUI 2.0 Console**.

---

## Release Summary

v0.7.0 marks the transition of ETL-SQL into a complete, enterprise-ready data orchestration and analytics platform. This milestone release introduces **Interactive Dashboards** featuring advanced drill-downs, cross-visual highlighting, and 7 new chart types (including Maps and Gauges). Script development is modernized through **VS Code ETL Notebooks** for stateful, cell-based query runs, and a major **TUI 2.0** console rewrite. Data sharing and governance are established via **Shared Datasets** and the **Lineage 2.0 Engine** (with 20 standard metadata tags and OpenLineage/Mermaid exports). Platform deployment is packaged through official Windows MSI, Linux `.deb`, and macOS DMG installers.

---

## ⚠️ Breaking Changes & Required Actions

- **`VISIBLE` keyword standardization:** The legacy report property `HIDDEN` has been removed. Update report scripts to use the unified `VISIBLE = ON | OFF` syntax.
- **DIRECTORY path connection types:** Statements such as `COPY DIRECTORY` and `FILE_LIST` now require path arguments to resolve to defined `DIRECTORY` connection aliases.

---

## ⏳ Deprecations

- **`HIDDEN` report property**: Removed in favor of `VISIBLE`.

## Highlights

### Interactive Dashboards & Analytical Drill-downs

**Audience:** Report Consumers · Script Authors

**Problem:** Static reports require developers to build multiple visual variants to satisfy simple user requests, cluttering dashboards and making deep-dive data analysis slow.

**Solution:** A comprehensive suite of interactive controls and visual primitives:
- **Hierarchical Drill-Downs:** Drill-down (`DRILL_IN` and `DRILL_DOWN`) statements support drilling directly into rows, while `DRILL_TO` navigates to other reports while transferring parameter states.
- **Cross-Visual Highlighting:** Clicking segments in one chart automatically filters matches and displays ghost-dimmed outlines for unrelated items across all other visuals.
- **New Visual Primitives:** Adds `MAP` (GeoJSON support), `GAUGE`, `BOXPLOT`, `WATERFALL`, `BUBBLE`, `RADAR`, and `CANDLESTICK` charts.
- **Input Controls:** Adds `TEXTBOX`, `NUMBERBOX`, `CHECKBOX`, `SLIDER`, `SEARCH`, `MULTISELECT`, and `RELDATEPICKER`.
- **Deferred Run:** Bind filters to a `RUN` action button to batch parameter changes together before executing a refresh, preventing constant visual flickering.

---

### ETL Notebooks (`.etlnb`) & VS Code Extension

**Audience:** Script Authors

**Problem:** Writing and debugging multi-step ETL scripts in a single flat file requires running the entire script repeatedly, making iterative development slow.

**Solution:** Native VS Code ETL Notebook support:
- Execute SQL queries in independent, cell-based blocks.
- Preserve stateful variable scopes and `#temp` tables in-memory via a background REPL process.
- Unified dot-aware autocomplete suggestions and lineage hovers inside notebook cells.
- Atomic process lifecycle tracking and heartbeats over Windows pipes ensure execution stability.

---

### Shared Datasets & Lineage 2.0 Engine

**Audience:** Administrators · Script Authors

**Problem:** Multi-step pipelines often re-query the same staging tables or files repeatedly across different reports, leading to database load and inconsistency.

**Solution:** A global cached dataset registry combined with a metadata lineage manager:
- **Shared Datasets:** Reports fetch data centrally from a cached repository, running refresh queries in the background and enforcing row-level access permissions.
- **Lineage 2.0:** Employs a library of 20 metadata tags (e.g. `@pii`, `@sensitive`) with a "true-wins" inheritance model.
- **Lineage Exports:** Automatically packages lineage routes into OpenLineage JSON files or compiles them into visual Mermaid diagrams.

```sql
-- Tag a table column as containing PII
CREATE TABLE #staged_users (
  id INT,
  email VARCHAR(255) TAG '@pii = true'
);

-- Lineage metadata propagates automatically through select-into statements
SELECT id, email INTO #validated_users FROM #staged_users;
```

---

### TUI 2.0 Console Modernization

**Audience:** Script Authors

**Problem:** The initial TUI was a bare-bones terminal, lacking window scrollback, clipboard features, or formatted execution telemetry.

**Solution:** A major overhaul of the console-based editor interface:
- Smooth viewport scrolling, smart copying, and dedicated status displays.
- Unified dot-intelligent autocomplete providing priority-ranked suggestions and connection option completions.
- Formatted tabular data grids and text layouts inside terminal frames.

## Improvements

### Language & Engine
- Added Snowflake and BigQuery connectors.
- Added T-SQL/Snowflake-style `QUALIFY` clause support to filter against window functions.
- Added standard window `FILTER (WHERE ...)` clauses inside aggregates.
- Added implicit start values to loop constructs: `FOR @i TO 10`.
- Added cursor fetch status checks via `@@FETCH_STATUS`.
- Added `GO` batch separator support.

### Portal & Visualization
- Standardized visibility properties across all visuals.
- Added GFM-style table formatting inside report text blocks via `marked.js` integration.

### VS Code Extension & IDE
- Added preview panel support for new chart types (Bubble, Radar, Candlestick, Maps).
- Upgraded variables exploration and schema discovery sidebars.

---

## Performance

- **Optimized REPL communication** — JSON payloads are serialized over low-latency named pipes, preventing terminal delay during large query outputs.

---

## Security

- **JWT Secret Generator:** Added the `GENERATE JWT_SECRET` command to simplify generating secure cryptographically strong keys for Portal configurations.
- **Proactive Linter Blocks:** Security checks block unauthorized system file access and warn on destructive DML commands without transaction blocks.
- **File Decompression:** Added `DECOMPRESS FILE` and `DECOMPRESS DIRECTORY` utilities with zip-slip traversal protections.

---

## Bug Fixes

- Resolved a multiselect duplicate rendering issue in report filters.
- Fixed Markdown tables rendering as raw text blocks due to library interface mismatch.
- Resolved "white screen" browser hangs inside the Portal.
- Resolved path traversal errors when executing script exports across different drive letters on Windows.
