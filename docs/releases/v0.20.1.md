# ETL-SQL v0.20.1

**Released:** 2026-10-06
Security and quality hardening patch release resolving CodeQL scanning alerts across ReportRuntime and enforcing zero open alerts in release workflows.

---

## Release Summary

ETL-SQL v0.20.1 is a targeted security and quality hardening patch following the v0.20.0 release. It sanitizes SVG rendering and XML parsing against entity expansion and injection vectors across charts and tables, eliminates format-string and DOM manipulation risks in parameter inputs, and refines CodeQL scanning workflows to establish a clean zero-alert security baseline.

- None in this release.

---

## Highlights

### SVG Entity Expansion & DOM Injection Hardening

**Audience:** Report Consumers · Administrators

Dynamic SVG rendering across charts, sparklines, and custom table cells now routes through safe parsing that strictly rejects `<!DOCTYPE` and `<!ENTITY` declarations before feeding input to browser DOM parsers. This eliminates XML bomb (`js/xml-bomb`) entity expansion risks and enforces safe SVG element mounting without exposing client-side DOM injection sinks.

### Zero-Alert CodeQL Security Baseline

**Audience:** Administrators · Evaluators

The CodeQL analysis workflow and release checklist now enforce zero open security and quality alerts as an automated pre-tagging release gate. Client-side runtime assets and generated bundles are properly scoped to prevent redundant alert duplication, ensuring continuous static analysis accurately reflects the application attack surface.

---

## Improvements

### Portal & Visualization

- Parameter control input validation warnings pass regex patterns as explicit arguments rather than template-interpolated strings (`js/tainted-format-string`).
- Multiselect filter controls construct button labels using semantic DOM elements and `textContent` rather than `innerHTML`.
- Native charts, tables, and card sparklines utilize strict SVG parsing validation.

---

## Performance

- No performance regressions. Client-side SVG validation adds sub-millisecond regex verification prior to DOM tree injection.

---

## Security

- **XML Entity Expansion (`js/xml-bomb`):** Guarded dynamic SVG parsing in `rt-util.ts`, `rt-charts.ts`, and `rt-table.ts` against entity recursion and external entity injection.
- **Client-Side DOM Manipulation (`js/xss`):** Replaced innerHTML usage in multiselect toggles with safe element creation and `textContent`.
- **Tainted Format String (`js/tainted-format-string`):** Corrected `console.warn` pattern logging in input control validation.
- **CodeQL Scanning Pipeline:** Updated workflow paths-ignore and query exclusions to maintain a clean zero-alert baseline across both C# and JavaScript/TypeScript suites.

---

## Bug Fixes

- Fixed potential XML parser stalls when handling malformed or adversarial SVG strings in visual exports.
- Resolved format string warning triggers in report parameter validation.
- Fixed unescaped character display in multiselect dropdown toggle labels.
