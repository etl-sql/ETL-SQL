# ETL-SQL v0.6.0 *(Unofficial)*

**Released:** 2026-05-11

Introducing **interactive chart drill-downs**, **cross-visual highlights**, and **shared dataset management** inside the Report Portal.

---

## Release Summary

v0.6.0 is an unofficial pre-release that lays the groundwork for interactive analytics. This version implements Power BI-style **cross-visual highlighting** (dimming/ghosting chart segments during selections) and hierarchical **drill-downs** (`DRILL_IN`/`DRILL_DOWN`) for reports. It also introduces **Shared Dataset Management**, allowing cached data extracts to be cataloged, shared across reports, and refreshed in the background.

## Highlights

### Interactive Analytics: Drill-Down & Highlights

**Audience:** Report Consumers · Script Authors

**Problem:** Standard reports were static, requiring developers to write distinct queries and layout blocks for every drill path, making exploration slow.

**Solution:** Native runtime interactivity:
- **Hierarchical Drill-Down:** Implements `DRILL_IN` and `DRILL_DOWN` parameters to explore lower-level data structures in place.
- **Cross-Visual Highlights:** Clicking a segment in one visual dims unrelated items across other page visuals.
- **Visual Controls:** Adds collapsible drawer containers, standard `VISIBLE = ON|OFF` parameters, and support for custom GeoJSON maps (`MAP_FILE`).

---

### Shared Dataset Management

**Audience:** Administrators · Script Authors

**Problem:** Multiple dashboard reports fetching the same data repeatedly creates resource bottlenecks on backing databases and slows down dashboard load times.

**Solution:** Integrated shared datasets:
- Centralized dataset persistence and caching.
- Access control lists to restrict datasets to authorized folders.
- Async Portal-triggered refreshes to run calculations in the background.
