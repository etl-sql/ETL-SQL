- WorkstationEditor lacked the `.geojson` MIME mapping already present in other hosts. Added
  `application/geo+json`. The new HTTP regression failed before the fix; all 65 scoped editor tests
  pass after it.
- The VSIX excluded all dependency `lib/umd` files, including the main module required by
  `vscode-languageserver-types`. Real activation failed before the fix. The exclusion is removed,
  and archive validation now verifies dependency manifest entry points. Focused entry-point tests
  and the full VSIX coordinator regression pass.
- Browser type and lint gates report zero findings. All 119 consumer checks pass.
- CodeQL now includes production build/package scripts and release-branch runs. The coverage check

  No scan of this changed configuration has been reviewed yet.
