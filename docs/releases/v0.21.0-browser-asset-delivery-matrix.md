# v0.21.0 Browser Asset Delivery Matrix

Tracks which delivery paths have been accepted with generated browser JavaScript absent from the
Git index. The workflow and rules are in
[Report Runtime Asset Standards](../architecture/standards/report-runtime-asset-standards.md); the
task list is `TODO.md` §1.1.

A row is **Accepted** only when its checks passed against the candidate named below. Evidence from
an earlier source state is **Supporting**: it shows the path worked once and must be rerun.
A platform that cannot be exercised stays **Open** unless that artifact leaves the release scope.
