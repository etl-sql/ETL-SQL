# ETL-SQL v0.23.1

**Status:** Draft

## Release summary

v0.23.1 adds screen-fit dashboard pages and governs which callers and scheduled jobs
can invoke external tools. Administrators can require native executables to match an
approved digest on restricted Windows and Linux workers.

## Breaking changes and required actions

- Back up the machine tool catalog, then upgrade the Orchestrator and its CLI workers
  together. Grant each affected user, group, or service permission to use the tool in its
  tenant. For scheduled jobs, configure the live Portal owner lookup and have the owner
  approve the current saved inline script. Restore the catalog backup if you roll back to
  older workers after editing catalog entries.
- Before enabling native artifact approval, stage approved artifacts in the protected
  store and retain older versions needed by running jobs and checkpoints. Windows requires
  the dedicated restricted virtual service profile and service-specific credentials.

See the [upgrade notes](../guides/onboarding/migration-guide.md#v0231-upgrade-notes) and
[tool grant reference](../reference/cli/admin-machine-tool-grant.md).

## Reporting

Dashboard authors can set `FIT = 'SCREEN'`, `MIN_HEIGHT`, and `ROW_WEIGHTS`. Chart
canvases adapt to their tiles and tables scroll inside their cards. Report refreshes
dispose of the old page's resize listeners, and table subtitles remain visible on mobile.

[Page options](../reference/visuals-reporting/report/page.md#page-options-and-styling)

## Native tool approval

Restricted Linux workers support direct ELF executables and fixed dash scripts.
Restricted Windows x64 workers support direct PE executables. An administrator can
activate an approved version, rotate to a new version, and roll back to a retained version.

[Operator configuration and approval procedures](../administration/orchestration/orchestrator-portal.md#approve-native-tools-on-a-restricted-linux-host)

## Certification status

The restricted Windows service qualification receipts cover the earlier qualification
MSI. The v0.23.1 candidate requires its own installed MSI receipts.
