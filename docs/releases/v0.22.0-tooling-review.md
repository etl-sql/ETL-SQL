# v0.22.0 Release Tooling Review

The v0.22.0 security review covered `src/` only. This is the record of the follow-up review of
`scripts/`, the installers and `tests/`, 2026-11-09 to 2026-11-10. It was moved out of `TODO.md` §4
on 2026-11-10; the open work stays there. Product fixes are also in `CHANGELOG.md`.

Most findings share one shape: a gate that passed after checking nothing.

run was rejected on a UTC−6 host). Guards added: the dataset secret scan must read both persisted
datasets and the export, the report help lint must find examples, and
`verify-source-only-preparation` fails an inventory with no outputs.

## Confirmed, held for v0.23.0

- TRANSFORM ignores `SET WHAT_IF ON` (TR02).
- `STRING_AGG` gives `'a,,b'`; `REPLACE`, `CHARINDEX` and `POSITION` on NULL (SQ06, SQ14).
- `FIRST_VALUE` ignores a `ROWS` frame (SQ12).
- The evaluator itself still reads an unknown column as `NULL` outside the temp-table case, and the
  lexer skips unknown characters silently (SQ03). Failing closed broke 7 of 10,366 engine tests that
  rely on outer-join rows carrying no columns for the missing side.
- `Compare-CertBaseline` does not flag a baseline scenario missing from the new report. No release
  path filters scenarios.

Did not reproduce on temp tables; recheck on the paths the review names before fixing: WHERE
pushdown with a shared column name, SEMI/ANTI NULL keys and residual `ON` terms, composite
sort-merge join at 3,000 rows, running `SUM() OVER (ORDER BY)`.
