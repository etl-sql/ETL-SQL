## Finding corrected in the working tree

Normal-batch controls reproduced the streaming slowdown only under the hidden Windows parent.

the reservation is released; gates are disposed only after the drain. Five deterministic regressions
hold execution cleanup or the initial database write, check refusal of new work, and verify that a
cancelled caller wait leaves the drain running. All 37 focused execution, trust, API contract and
factory-disposal cases pass without skips. Full final-candidate validation remains required.
