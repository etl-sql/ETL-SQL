## Upgrade

Upgrades are supported from v0.22.0. Back up configuration, databases and keys before changing an
installation.

On Windows the MSI no longer configures the services: the Orchestrator and Portal create their
secrets on first start, `appsettings.json` keeps only your settings, and the release defaults move
to `appsettings.defaults.json`. An upgrade from v0.22.0 keeps your `appsettings.json` and removes,
once, the values equal to the v0.22.0 defaults. See
[Windows installation](../administration/platform/installation.md#windows).
