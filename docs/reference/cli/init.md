# etl-sql init

Scaffold a starter configuration and first ETL-SQL script for new users

## Synopsis

```text

```

## Arguments

| Argument | Required | Description |
| :--- | :--- | :--- |
| `directory` | no | Target directory to scaffold into (default: current directory). |

## Options

| Option | Description |
| :--- | :--- |
