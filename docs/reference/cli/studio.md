# etl-sql studio

Launch the modern ETL-SQL Studio visual & script workbench on local loopback

## Synopsis

```text
etl-sql studio [file] [options]
```

## Arguments

| Argument | Required | Description |
| :--- | :--- | :--- |
| `file` | no | Optional script file or directory to open in Studio |

## Options

| Option | Description |
| :--- | :--- |
| `--no-browser` | Do not automatically open the browser on start |
| `--port, -p` | Port to listen on (default: auto-assigned ephemeral port) |
