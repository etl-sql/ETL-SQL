# etl-sql admin disable-connection

Disable a shared connection so SHARED:alias fails until it is re-enabled

## Synopsis

```text
etl-sql admin disable-connection [options]
```

## Options

| Option | Description |
| :--- | :--- |
| `--alias, -a` | Catalog alias scripts reference as SHARED:alias (letters, numbers, period, underscore, hyphen). |
