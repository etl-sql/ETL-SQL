# etl-sql purge

Delete all ETL-SQL runtime data (reports, snapshots, databases, logs, sessions)

## Synopsis

```text
etl-sql purge [options]
```

## Options

| Option | Description |
| :--- | :--- |
| `--dry-run` | List the data that would be removed without deleting anything. |
| `--yes, -y` | Skip the confirmation prompt (for scripts and installers). |
