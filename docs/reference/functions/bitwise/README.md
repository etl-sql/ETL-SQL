# Bitwise Functions

Bitwise functions operate on the individual bits of integer values.

## Functions

- [BIT_COUNT](bit_count.md) - Returns the number of set bits (popcount) in the binary representation of an integer.
- [BITAND](bitand.md) - Performs a bitwise AND operation on two integers.
- [BITNOT](bitnot.md) - Performs a bitwise NOT (complement) operation on an integer.
- [BITOR](bitor.md) - Performs a bitwise OR operation on two integers.
- [BITSHIFTLEFT](bitshiftleft.md) - Performs a bitwise left shift on an integer.
- [BITSHIFTRIGHT](bitshiftright.md) - Performs a bitwise right shift on an integer.
- [BITXOR](bitxor.md) - Performs a bitwise XOR (exclusive OR) operation on two integers.
