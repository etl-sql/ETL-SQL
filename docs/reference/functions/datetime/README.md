# DATETIME Reference

[« Back to parent](../README.md)

| Page | Description |
| :--- | :--- |
| [CURRENT_DATE](current_date.md) | Returns the current date (no time component). |
| [CURRENT_TIME](current_time.md) | Returns the current time of day. |
| [CURRENT_TIMESTAMP](current_timestamp.md) | Returns the current UTC date and time. `CURRENT_TIMESTAMP` is equivalent to `GETDATE()` and `NOW()`. |
| [DATE_PART](date_part.md) | Extracts a specified date part component from a date as an integer value. |
| [DATE_TRUNC](date_trunc.md) | Truncates a datetime to the beginning of the specified date part boundary. |
| [DATEADD](dateadd.md) | Adds a specified number of date/time units to a date or datetime value. |
| [DATEDIFF](datediff.md) | Returns the count of date/time part boundaries crossed between two dates. |
| [DATENAME](datename.md) | Returns the name of a specific date part as a string. |
| [DATEPART](datepart.md) | Returns the integer value of a specific date part from a date or datetime. |
| [DATETIMEFROMPARTS](datetimefromparts.md) | Constructs a DATETIME value from individual year, month, day, hour, minute, second, and millisecond components. |
| [DATETIMEOFFSETSFROMPARTS](datetimeoffsetsfromparts.md) | Constructs a DATETIMEOFFSET value from individual date, time, and timezone offset components. |
| [DATETRUNC](datetrunc.md) | Truncates a date to the beginning of the specified date part boundary. |
| [DAY](day.md) | Returns the day-of-month component of a date as an integer (1–31). |
| [END_OF_MONTH](end_of_month.md) | Returns the last day of the month for a given date, optionally offset by a number of months. |
| [END_OF_QUARTER](end_of_quarter.md) | Returns the last day of the calendar quarter containing a given date. |
| [END_OF_WEEK](end_of_week.md) | Returns the Saturday that ends the week containing a given date. |
| [EOMONTH](eomonth.md) | Returns the last day of the month for a given date, optionally offset by a number of months. |
| [EXTRACT](extract.md) | Extracts a specified date part component from a date or time expression. |
| [GETDATE](getdate.md) | Returns the current local date and time of the host machine. |
| [HOUR](hour.md) | Returns the hour component of a datetime as an integer (0–23). |
| [ISDATE](isdate.md) | Returns `1` when a string can be parsed as a valid date or datetime, and `0` otherwise. |
| [MINUTE](minute.md) | Returns the minute component of a datetime or time value as an integer from `0` through `59`. |
| [MONTH](month.md) | Returns the month component of a date as an integer (1–12). |
| [NOW](now.md) | Returns the current UTC date and time. `NOW()` is an alias for `GETDATE()`. |
| [RELDATE](reldate.md) | Resolves a relative date expression string into a standard DATETIME value. |
| [SAME_PERIOD_LAST_YEAR](same_period_last_year.md) | Returns the corresponding date exactly one year earlier, for year-over-year comparisons. |
| [SECOND](second.md) | Returns the second component of a datetime or time value as an integer from `0` through `59`. |
| [START_OF_MONTH](start_of_month.md) | Returns the first day of the month containing a given date. |
| [START_OF_QUARTER](start_of_quarter.md) | Returns the first day of the calendar quarter containing a given date. |
| [START_OF_WEEK](start_of_week.md) | Returns the Sunday that begins the week containing a given date. |
| [SYSDATE](sysdate.md) | Returns the current date and time from the system hosting the ETL-SQL engine. `SYSDATE` is the Oracle-compatible alias. |
| [TIMEFROMPARTS](timefromparts.md) | Constructs a TIME value from individual hour, minute, second, fractional, and precision components. |
| [TO_DATE](to_date.md) | Converts a string representation of a date to a `DATE` value. |
| [TO_TIMESTAMP](to_timestamp.md) | Converts a Unix epoch timestamp (number of seconds since `1970-01-01 00:00:00 UTC`) to a standard date/time representation. |
| [TRUNC](trunc.md) | Truncates the time portion of a datetime, returning the date at midnight. |
| [YEAR](year.md) | Returns the year component of a date as an integer. |
