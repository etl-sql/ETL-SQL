# STDDEV
Returns the sample standard deviation of a set of values. Alias for STDEV.

**Category:** Aggregates

## Syntax
`sql
STDDEV(expression)
`

## Example
`sql
SELECT STDDEV(Sales) FROM MonthlySales;
`
