# WINDOW Reference

[« Back to parent](../README.md)

| Page | Description |
| :--- | :--- |
| [CUME_DIST](cume_dist.md) | Returns the cumulative distribution of the current row within its partition. |
| [DENSE_RANK](dense_rank.md) | Assigns a rank to each row with no gaps for tied ranks. |
| [FIRST_VALUE](first_value.md) | Returns the first value in the current window frame. |
| [LAG](lag.md) | Returns the value of an expression from a previous row within the partition. |
| [LAST_VALUE](last_value.md) | Returns the last value in the current window frame. |
| [LEAD](lead.md) | Returns the value of an expression from a subsequent row within the partition. |
| [NTH_VALUE](nth_value.md) | Returns the value of an expression at the n-th row of the window frame. |
| [NTILE](ntile.md) | Divides rows within a partition into N approximately equal buckets and assigns a bucket number. |
| [PERCENT_RANK](percent_rank.md) | Returns the relative rank of the current row within its partition (0 to 1). |
| [RANK](rank.md) | Assigns a rank to each row within a partition. Tied rows receive the same rank; the next rank has a gap. |
| [ROW_NUMBER](row_number.md) | Assigns a unique sequential integer to each row within a partition, starting at 1. |
