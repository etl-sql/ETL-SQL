# Job State Functions

Job state functions read and write durable per-job state for orchestrated runs.

## Functions

- [GET_JOB_STATE](get_job_state.md) - Returns the saved state value for the current script or job execution context.
- [SET_JOB_STATE](set_job_state.md) - Sets a saved state value for the current script or job execution context.
