# Regular Expression Functions

Regular expression functions match, extract, split, and replace text using patterns.

## Functions

- [REGEXP_COUNT](regexp_count.md) - Returns the number of times a regular expression pattern matches within a string.
- [REGEXP_INSTR](regexp_instr.md) - Returns the 1-based position of the first (or Nth) regex match in a string.
- [REGEXP_LIKE](regexp_like.md) - Returns 1 if a string matches a PCRE regular expression pattern, 0 otherwise.
- [REGEXP_MATCHES](regexp_matches.md) - Returns all regular expression matches in a string as rows.
- [REGEXP_REPLACE](regexp_replace.md) - Replaces occurrences of a regex pattern in a string.
- [REGEXP_SPLIT_TO_TABLE](regexp_split_to_table.md) - Splits a string into rows using a regular expression separator.
- [REGEXP_SUBSTR](regexp_substr.md) - Returns the portion of a string matched by a regex pattern.
