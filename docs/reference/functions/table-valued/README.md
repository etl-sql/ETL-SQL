# Table-Valued Functions

Table-valued functions return a result set that can be selected from like a table.

## Functions

- [CONNECTION_PROPERTY](connection_property.md) - Looks up an active connection by name and retrieves its metadata properties.
- [GENERATE_SERIES](generate_series.md) - Returns a table of sequential numeric values within a range.
