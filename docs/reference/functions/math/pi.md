# PI
Returns the value of the mathematical constant pi ($\pi$).

**Category:** Math

## Syntax
```sql
PI()
```

## Parameters
None.

## Returns
`DECIMAL` — The value of $\pi$ (approximately 3.141592653589793).

## Example
```sql
SELECT PI();            -- → 3.141592653589793
```
