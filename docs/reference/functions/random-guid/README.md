# Random and GUID Functions

Random and GUID functions generate random values and unique identifiers.

## Functions

- [NEWID](newid.md) - Generates a new globally unique identifier (UUID v7, time-ordered).
- [NEWSEQUENTIALID](newsequentialid.md) - Generates a new sequential identifier value.
- [RANDOM](random.md) - Returns a pseudo-random decimal value greater than or equal to `0` and less than `1`.
- [RANDOM_DECIMAL](random_decimal.md) - Returns a random DECIMAL within an inclusive range.
- [RANDOM_INT](random_int.md) - Returns a random integer within an inclusive range.
