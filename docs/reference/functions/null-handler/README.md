# Null Handling Functions

Null handling functions substitute, detect, and compare NULL values.

## Functions

- [COALESCE](coalesce.md) - Returns the first non-NULL value from a list of expressions.
- [IFNULL](ifnull.md) - Returns a replacement value when an expression is `NULL`. `IFNULL` is an alias for [`ISNULL`](../null-handler/isnull.md).
- [IS_NOT_NULL](is_not_null.md) - Returns whether an expression is not `NULL`.
- [IS_NULL](is_null.md) - Returns whether an expression evaluates to `NULL`.
- [ISNULL](isnull.md) - Returns a replacement value when the expression is NULL.
- [NULLIF](nullif.md) - Returns NULL if two expressions are equal; otherwise returns the first expression.
- [NVL](nvl.md) - Returns a replacement when the first argument is NULL. Oracle-style alias for ISNULL.
- [NVL2](nvl2.md) - Returns one value if the expression is NOT NULL, and another if it IS NULL. Oracle-style conditional.
