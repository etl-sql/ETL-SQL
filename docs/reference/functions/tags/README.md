# Tag and Lineage Functions

Tag and lineage functions read column and dataset tags for governance and lineage.

## Functions

- [GET_TAG_VALUE](get_tag_value.md) - Retrieves the metadata tag value assigned to a specific table or column.
- [GET_TAGS](get_tags.md) - Returns metadata tag names defined on a table or column.
- [HAS_TAG](has_tag.md) - Checks if a metadata tag exists on a table or column, optionally validating its expected value.
