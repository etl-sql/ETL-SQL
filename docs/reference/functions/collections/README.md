# Collection Functions

Collection functions build, combine, and reshape list and array values.

## Functions

- [ADD_TO_LIST](add_to_list.md) - Returns a list with a value appended. `ADD_TO_LIST` is an alias for [`APPEND_TO_LIST`](append_to_list.md).
- [APPEND_TO_LIST](append_to_list.md) - Returns a list with a value appended.
- [GREATEST](greatest.md) - Returns the largest value from a list of arguments.
- [LEAST](least.md) - Returns the smallest value from a list of arguments.
- [REMOVE_FROM_LIST](remove_from_list.md) - Returns a list with matching values removed.
- [SORT_LIST](sort_list.md) - Returns a sorted copy of a list.
