# Error Functions

Error functions expose details of the active error inside a `TRY ... CATCH` block.

## Functions

- [ERROR_LINE](error_line.md) - Returns the script line number associated with the current error inside a `CATCH` block.
- [ERROR_MESSAGE](error_message.md) - Returns the message for the current error inside a `CATCH` block.
- [ERROR_NUMBER](error_number.md) - Returns the numeric code for the current error inside a `CATCH` block.
- [ERROR_SEVERITY](error_severity.md) - Returns the severity value for the current error inside a `CATCH` block.
- [ERROR_STATE](error_state.md) - Returns the state value for the current error inside a `CATCH` block.
