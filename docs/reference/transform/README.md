# Table Transformation Algorithms

[« Back to parent](../README.md)

Table transformations are invoked using the `TRANSFORM` DML statement.

| Algorithm | Description |
| :--- | :--- |
| [FILL_DATES](fill_dates.md) | Fills missing daily rows in a time-series dataset. |
| [INTERPOLATE](interpolate.md) | Fills missing numeric values between known data points in a series. |
| [DEDUPLICATE](deduplicate.md) | Removes duplicate rows based on key columns, with optional sorting. |
| [PIVOT](pivot.md) | Rotates rows into columns to build cross-tabulation summaries. |
| [TOP_N_OTHERS](top_n_others.md) | Aggregates low-volume categories into a single row. |
| [PERIOD_COMPARISON](period_comparison.md) | Calculates period-over-period differences and growth. |
| [SHARE_OF_TOTAL](share_of_total.md) | Computes percentage contribution relative to a group or grand total. |
| [NORMALIZE](normalize.md) | Scales numeric columns using Min-Max or Z-Score. |
| [ROLLING_AGGREGATE](rolling_aggregate.md) | Smooths data using rolling/moving window aggregations. |
