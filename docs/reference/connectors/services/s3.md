# S3
Connects to Amazon S3 or S3-compatible cloud object storage providers (e.g. Cloudflare R2, MinIO, Google Cloud Storage, Wasabi). Implements remote file transfer and directories management.

Syntax:
  CREATE CONNECTION <name> AS S3(
    BUCKET           = 'my-bucket-name',
    ACCESS_KEY       = 'my-access-key',
    SECRET_KEY       = '<secret-key>',
    SESSION_TOKEN    = '<session-token>',
    ENDPOINT         = 'https://my-custom-endpoint.com',
    REGION           = 'us-east-1',
    FORCE_PATH_STYLE = 'TRUE' | 'FALSE'
  );

Aliases:
  AWS_S3

Options:
- **BUCKET** — S3 bucket name context (required)
- **ENDPOINT** — custom endpoint URL for S3-compatible vendors (R2, MinIO, GCS, Wasabi)
- **ACCESS_KEY** — cloud connection access key ID (omit for anonymous/public access)
- **SECRET_KEY** — cloud connection secret access key (omit for anonymous/public access)
- **SESSION_TOKEN** — temporary IAM security session token
- **REGION** — AWS region context (default: us-east-1)
- **FORCE_PATH_STYLE** — set to TRUE to force path-style addressing (required for MinIO, LocalStack)

```sql
-- Connect to AWS S3 bucket
CREATE CONNECTION MyS3 AS S3(
  BUCKET     = 'corporate-data-dump',
  ACCESS_KEY = @s3_access,
  SECRET_KEY = @s3_secret,
  REGION     = 'us-west-2'
);

-- Check if remote file exists
IF FILE_EXISTS('daily_inbound/sales.csv') AT MyS3
BEGIN
  -- Download remote file to local disk
  RECEIVE FILE 'daily_inbound/sales.csv' TO 'C:\Import\sales.csv' FROM MyS3;
  
  -- Delete remote file after ingestion
  DELETE FILE 'daily_inbound/sales.csv' AT MyS3;
END;

-- Upload local output to S3
SEND FILE 'C:\Export\summary.parquet' TO 'processed/summary.parquet' AT MyS3;
```
