# Connectors

Connector reference pages define `CREATE CONNECTION` syntax, options, authentication patterns, security behavior, and examples.

## Connector Families

- [Database connectors](databases/mssql.md) - MSSQL, Postgres, Oracle, MySQL, SQLite, ODBC, Snowflake, BigQuery, MongoDB, and Neo4j.
- [File connectors](files/flatfile.md) - flat files, Excel, JSON, XML, Parquet, and Avro.
- [Service connectors](services/api.md) - API/REST, SFTP, FTP, Azure Blob, S3, SharePoint, SMTP, Kafka, Directory, Active Directory, and MockDB.
- [All connector options](data-connectors.md) - consolidated connector reference.

## Page Standard

Every connector page should include syntax, required options, authentication patterns, mutually exclusive options, security notes, examples, troubleshooting, and references.

Use [Connector Reference Template](../../templates/connector-reference-template.md) for new connector pages.
