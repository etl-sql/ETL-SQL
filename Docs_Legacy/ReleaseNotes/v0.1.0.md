# ETL-SQL v0.1.0 *(Unofficial)*

**Released:** 2026-03-13

The initial development proof-of-concept, establishing the **SQL parser**, **in-memory engine**, and **terminal text editor**.

---

## Release Summary

v0.1.0 is the first unofficial development snapshot of the ETL-SQL platform. Project development began on March 6, 2026, to design a zero-trust, pipeline-centric SQL engine. This release compiles the initial **Abstract Syntax Tree (AST) parser** and **core execution engine**, proving the concept by parsing SQL query files and loading CSV data directly into in-memory temp tables.

## Highlights

### Abstract Syntax Tree (AST) Parser & Core SQL Engine

**Audience:** Script Authors · Evaluators

**Problem:** Existing ETL frameworks required writing complex Python or drag-and-drop workflow diagrams, making version control difficult and preventing simple SQL-based scripting.

**Solution:** A custom parsing and execution pipeline:
- An AST compiler that parses SQL-like command tokens into logical execution plans.
- Core engine evaluating expressions, filtering datasets, and returning formatted results.
- Proof of concept: CSV file parser loading records directly into memory.

```sql
-- Initial syntax proof
SELECT name, age INTO #staged_users FROM CSV('users.csv');
SELECT * FROM #staged_users WHERE age > 21;
```

---

### Terminal editor foundations

**Audience:** Script Authors

**Problem:** Modifying and validating script logic required continuously opening files in separate text editors and executing command-line compilation runs.

**Solution:** A basic console-based TUI text editor:
- Renders directly inside CLI shells.
- Supports basic text entry, file saving, and output display pane splitting.
